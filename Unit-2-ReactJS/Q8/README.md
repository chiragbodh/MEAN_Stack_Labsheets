# Q8 — Create and run a React app

Student name is set to **Chirag Bodh** and course to **MCA**. Set your actual
college in `src/App.jsx`; the college name has not been provided.

Run the supplied project with `npm install` then `npm run dev`.

To demonstrate the creation command, use a separate empty practice directory:

```sh
npm create vite@latest myreact -- --template react
cd myreact
npm install
npm run dev
```

The prepared project pins its dependencies for reproducibility; the command
above creates the current Vite template. Install React Developer Tools from
the official extension-store link at https://react.dev/learn/react-developer-tools.
Open its Components tab after loading the app.

profile card and React Developer Tools Components tab.
