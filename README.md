# MCFS203P MEAN Stack Practical Lab Sheets

Student: **Chirag Bodh**  
Course: **MCA**  
GitHub: **chiragbodh**

Source code and instructions for all 50 practicals in the supplied
MCFS203P-AS01 lab sheet, organized in independent folders Q1 through Q50.
The assignment includes Node.js, React, Angular and MongoDB.

## Start here

- Read [SETUP.md](SETUP.md) for installation and run commands.
- Open a question folder and read its README before running the program.
- Read [VERIFICATION.md](VERIFICATION.md) for what was actually tested and
  what still needs local verification.
- Follow [SCREENSHOT_CHECKLIST.md](SCREENSHOT_CHECKLIST.md) to collect the
  code and running-output evidence required by the assignment.

Q8 retains `Your College Name` until the correct college name is supplied.
Q18 has a sample avatar that should be replaced with your own photo.
Roll number, semester, faculty and submission date have not been invented.
Names and marks in multi-student exercises are sample data.

were added and React configuration was corrected. Q14–Q50 were added to cover
the uploaded assignment. No third-party dependency source or node_modules is
copied into this repository; npm installs the declared dependencies.
